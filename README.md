# README

## Summary

Workspace intends to provide a space for AI agent(s) to work in the context of an Obsidian vault.

## Usage

In the Obsidian vault root, add a redirecting CLAUDE.md:
 `# Claude Code Bootstrap

 Primary instructions live in `Workspace/CLAUDE.md`.

 Read that file first and follow it.`

Open Claude Code in the root of the Obsidian vault.
